# Primeiros Passos no PSOL

**Site:** https://wladimirgramacho.github.io/psol-onboarding/

Guia de integração para novas filiadas e novos filiados do PSOL: 9 passos com tarefas, busca de diretório por estado (com as cidades de Santa Catarina como exemplo) e um teste rápido.

Todo o conteúdo foi resumido de páginas públicas e oficiais do PSOL (psol50.org.br, psol50sc.org, flcmf.org.br e outras), conferidas em 23/11/2026. As fontes estão listadas no fim da página.

O site não coleta dados: o progresso de cada pessoa fica salvo apenas no navegador dela.

## Como editar

- Edite `onboarding.html` (conteúdo, estilos e scripts estão nesse arquivo).
- Rode `sh build.sh` para gerar o `index.html`, que é a página publicada.
